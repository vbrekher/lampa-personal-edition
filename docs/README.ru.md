# Lampa Personal Edition — инструкция на русском

**Своя Lampa для Samsung TV: настройки вводятся на компьютере, а не пультом телевизора.**

Это независимый форк [Lampa](https://github.com/yumata/lampa-source). Ты собираешь приложение из исходного кода, выбираешь язык и при необходимости указываешь адрес своего TorrServer. Полученный `WGT` устанавливаешь через Apps2Samsung.

Никакой отдельный сервер Lampa, Bunny или VPS **не обязателен**. Фильмы и сериалы в WGT не содержатся; приложение обращается к интернет-сервисам каталога и к указанным тобой источникам.

> Это первая версия адаптера. Установка и воспроизведение на реальном Samsung ещё **не подтверждены**. Тесты сборки не заменяют проверку телевизора.

## 1. Что понадобится

- Mac или Linux с Node.js 18+ и npm.
- Команды `zip`, `unzip` и интернет для установки зависимостей.
- Samsung Smart TV с Tizen 5.0+ и включённым Developer Mode.
- [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung/releases).
- **Необязательно:** собственный TorrServer, доступный с телевизора.

## 2. Скачай исходный код и запусти сборку

Открой Terminal на Mac:

~~~bash
git clone https://github.com/vbrekher/lampa-personal-edition.git
cd lampa-personal-edition
npm install
npm run build:personal
~~~

Сборщик задаст три вопроса:

1. **Язык**: `ru` по умолчанию. Также поддерживаются `en`, `uk`, `fr`, `pl`, `es` и другие языки оригинальной Lampa.
2. **TorrServer URL**: можно пропустить. Если он есть — укажи полный адрес, например `http://192.168.1.25:8090`. Сервер должен работать отдельно и открываться с телевизора.
3. **Сторонние плагины**: по умолчанию отключены. Включай только если понимаешь их риски.

Сборщик **не спрашивает пароли и не выполняет вход в CUB**. Не вставляй логин, пароль или секретный токен в URL.

После успешной сборки появится:

~~~text
dist/Lampa-Personal-Edition.wgt
~~~

Скомпилированный код Lampa находится внутри файла. Оригинальный загрузчик, скачивающий главный JS с публичного сайта, исключён.

## 3. Установи WGT на Samsung

1. Открой **Apps** на телевизоре и настройки приложений.
2. Набери `12345`, включи **Developer Mode**, укажи IP своего компьютера и перезагрузи телевизор.
3. Убедись, что телевизор и компьютер в одной сети.
4. Запусти Apps2Samsung на компьютере.
5. Выбери телевизор → установку **Custom WGT** → файл `dist/Lampa-Personal-Edition.wgt`.
6. Если потребуется, разреши Apps2Samsung переподписать пакет.
7. На телевизоре открой **Lampa Personal Edition**.

Имя и идентификатор приложения отличаются от оригинальной Lampa: существующую установку заменять не требуется.

## 4. Проверка

Открой Lampa, проверь главное меню, навигацию пультом и каталог. Если настроен TorrServer, проверь доступность своего сервера в настройках. Работа каталога не гарантирует, что видео декодируется: проверяй воспроизведение отдельно.

## 5. Как изменить настройки

Выполни `npm run build:personal` ещё раз, укажи новые параметры и установи новый WGT. Собранные настройки применяются при запуске.

## 6. Частые вопросы

**Нужен ли Bunny?** Нет. Приложение собирается и работает на телевизоре без собственного хостинга Lampa.

**Можно ли обойтись без TorrServer?** Да. Укажи пустой адрес. Тогда приложение используется как каталог; возможности конкретных источников зависят от оригинальной Lampa.

**Где фильмы и сериалы?** Это каталог, а не сборник контента. В WGT нет видеозаписей или встроенного TorrServer.

**Безопасно ли включать плагины?** Сторонний плагин может выполнять JavaScript в контексте приложения. Включение — только по желанию и на свой риск.

**Работает ли на моём Samsung?** Сборщик рассчитан на Tizen 5.0+, но реальные испытания этой версии на телевизоре пока не завершены.

## 7. Безопасность и лицензия

WGT содержит конфигурацию и адрес сервера в обычном виде. Не размещай в нём секретные данные и не публикуй персональный файл. Папка `dist/` игнорируется Git.
